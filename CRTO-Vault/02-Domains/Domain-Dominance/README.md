# Domain Dominance

Techniques for achieving and maintaining full control over an Active Directory domain once domain admin (or equivalent) access is obtained.

## Scope

- Golden Ticket (forging TGTs with the krbtgt hash)
- Silver Ticket (forging TGS for specific services)
- Diamond / Sapphire Tickets
- DCSync (replicating credentials from a DC)
- Skeleton Key
- AdminSDHolder abuse
