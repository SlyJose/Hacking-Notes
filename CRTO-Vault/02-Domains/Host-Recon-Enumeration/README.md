# Host Recon & Enumeration

Techniques for gathering information about the compromised host after gaining initial access. Understanding the host context drives your next moves — privilege escalation, credential access, or lateral movement.

## Scope

- Local user and group enumeration
- Running processes and services
- Installed software and security products
- Network configuration and connections
- Environment variables and system info
- Automated enumeration tools (Seatbelt, SharpUp)
