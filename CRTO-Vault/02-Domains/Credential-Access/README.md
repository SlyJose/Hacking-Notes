# Credential Access

Techniques for stealing credentials — hashes, tickets, plaintext passwords, and tokens — from a compromised host or Active Directory environment.

## Scope

- Kerberoasting and AS-REP Roasting
- Mimikatz (sekurlsa, lsadump)
- DPAPI abuse
- Token theft and impersonation
- LAPS password extraction
- Credential dumping from memory (LSASS)
