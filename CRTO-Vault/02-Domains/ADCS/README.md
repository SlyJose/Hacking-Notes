# ADCS (Active Directory Certificate Services)

Techniques for abusing misconfigured certificate templates and CA infrastructure to escalate privileges, persist, or forge authentication certificates.

## Scope

- ESC1 — Misconfigured certificate templates (enrollee supplies subject)
- ESC4 — Vulnerable certificate template ACLs
- ESC8 — NTLM relay to ADCS HTTP enrollment
- Certificate-based authentication
- Certificate request and enrollment
- CA enumeration
