# C2 Infrastructure & Cobalt Strike

Cobalt Strike setup, configuration, and operational usage. This is the backbone of CRTO — nearly every technique is executed through Beacon.

## Scope

- Team server setup and configuration
- Listeners (HTTP, HTTPS, SMB, TCP, DNS)
- Beacon commands and workflow
- Malleable C2 profiles
- Payload generation
- Session management and Beacon operations
- Aggressor scripts
