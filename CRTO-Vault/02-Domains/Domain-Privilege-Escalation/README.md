# Domain Privilege Escalation

Techniques for escalating from a standard domain user to domain admin or equivalent privileges within Active Directory.

## Scope

- Kerberos delegation abuse (unconstrained, constrained, RBCD)
- AS-REP Roasting
- ACL/ACE abuse (GenericAll, WriteDACL, etc.)
- Group Policy abuse
- Shadow Credentials
- S4U2Self / S4U2Proxy
