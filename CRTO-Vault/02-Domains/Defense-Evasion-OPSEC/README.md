# Defense Evasion & OPSEC

Techniques for avoiding detection by endpoint security products (AV, EDR, AMSI), network monitoring, and SOC analysts during red team operations.

## Scope

- AMSI bypass
- AppLocker / CLM bypass
- PPID spoofing and process injection
- Malleable C2 profiles for traffic blending
- Artifact and payload obfuscation
- Process hollowing and spawn-to
- Timestomping and log evasion
- Operational security best practices
