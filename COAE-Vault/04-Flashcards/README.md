# Flashcards

Spaced repetition cards organized by module. Uses the Obsidian Spaced Repetition plugin syntax.

- Tag each file with `#flashcards` and the module tag
- Single-line format: `Question::Answer`
- Multi-line format: Question on one line, `?` on next line, then answer

Create cards as you study — focus on concepts that are easy to confuse or forget.
