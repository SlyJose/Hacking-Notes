# Personal Notes

Your own gotchas, mistakes, "why did this fail" reflections, and lessons that don't fit neatly into a technique note.

These are the insights that come from hands-on experience — the stuff the course doesn't tell you. Examples:

- "I wasted an hour because my adversarial perturbation was clipped by the preprocessing pipeline"
- "The lab model API has rate limiting — batch your extraction queries or you'll get locked out"
- "Always check if the model normalizes inputs before crafting FGSM perturbations"
- "The report template expects CVSS-like severity — map AI-specific impacts to the standard scale"
